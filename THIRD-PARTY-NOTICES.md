## dadaspec

The Dadaspec style (`web/styles/dadaspec/`, and the same style in the desktop program) takes its name and its colouring idea from [dadaspec](https://github.com/dada-bots/dadaspec) by dadabots: one colour per moment from the balance of three frequency bands (below 200 Hz red, 200 to 1500 Hz green, 1500 Hz and above blue), with each bin setting the brightness. No dadaspec source code is included; the implementation here is separate. This project is not affiliated with or endorsed by dadabots. Details are in [web/styles/dadaspec/README.md](web/styles/dadaspec/README.md).
