First public release. This is a beta: see "Known issues" in the README before you rely on it.

**Try the web version: <https://lawchli.github.io/Spectrum-3D/>**

| File | For |
|---|---|
| `Spectrum-3D-0.3.0-beta.1-macos-universal.zip` | macOS 11 or later, Apple silicon and Intel |
| `Spectrum-3D-0.3.0-beta.1-windows-x64.zip` | Windows 10 or later, 64-bit. **Experimental** |
| `Spectrum-3D-0.3.0-beta.1-linux-x64.tar.gz` | Linux x86-64, glibc 2.35 or later. **Experimental** |
| `Spectrum-3D-0.3.0-beta.1-android.apk` | Android demo app, Android 8.0 or later |
| `spectrum-3d-0.3.0-beta.1.aar` | Android library |

The desktop packages are not signed with a developer certificate or notarised:

- macOS: right-click `Spectrum 3D.app` and choose Open. On macOS 15 and later, open it once, then press "Open Anyway" in System Settings, Privacy & Security.
- Windows: unzip the whole folder, run `Spectrum 3D.exe`, and choose "More info", then "Run anyway" if SmartScreen appears.

The Windows and Linux packages are built and unit-tested automatically but were not hand-tested for this release.
